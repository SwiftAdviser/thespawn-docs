## Why raw scores stay low

Claude Blog expects full article packages:

- 1,200-3,000 word body copy;
- `date` and `author` frontmatter;
- BlogPosting JSON-LD;
- hero image and image alt coverage;
- PDF and HTML render artifacts;
- long-form citation and E-E-A-T structure.

The Spawn docs pages are shorter task pages, API references, CLI references, and operations notes. Adding blog-only padding would make the docs worse. The useful part of this check is therefore the raw failure signal: it identifies where the blog rubric does not match the documentation artifact.

- Claude Blog raw audit recorded;

- live examples pass smoke checks;
- Mintlify broken links pass;
- local preview renders key pages;
- browser QA confirms the rewritten paths are visible.
