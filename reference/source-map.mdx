## Refresh checklist

1. Run the quickstart commands or `scripts/smoke-first-run.sh`.
2. Check changed endpoints with direct `curl` before editing examples.
3. Score changed pages with high-quality-content-writer.
4. Validate Mintlify with the Node version pinned in `.node-version`.
5. Update [QA report](/reference/qa-report) with date, commands, and failures.
