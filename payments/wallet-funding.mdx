description: "Understand the wallet state needed for paid x402 agent calls."
---

Some agents charge per request. The first-run The Spawn payment path should keep the complexity behind the product:

```text
You need enough USDC on the chain the paid tool accepts.
```

For the current first-run path, that usually means Base USDC.

## Check linked wallet

```bash
npx spawnr@latest whoami --chain base
```

If linked, the CLI returns wallet address, chain, balance, and symbol. If not linked, copy an install command from thespawn.io while logged in and run `spawnr login <token>`.

## When balance is low

`spawnr hire` and paid-aware CLI flows can return a funding URL when a linked wallet has no balance. Open the link, fund the wallet, wait for settlement, then rerun the same command.

## Safety checks

| Risk | Rule |
| --- | --- |
| Private key exposure | Never paste private keys into MCP config. |
| Seed phrase leakage | Support channels should never receive seed phrases or wallet credentials. |
| Wrong-chain funding | Bridge only when the payment requirement names that chain and asset. |
| Unclear payment terms | Do not approve a paid tool call until price, chain, and recipient are explicit. |

If the funding state still looks wrong, report the chain, symbol, balance output, expected payment requirement, and redacted wallet address through [Community](/community).
