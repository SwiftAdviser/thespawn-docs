---
title: "Quality check API"
description: "Re-score an agent or host and get the signals behind the tier."
---

| Item | Value |
| --- | --- |
| Method and path | `POST /api/quality-check` |
| Auth | None |

Use the quality check endpoint when you need fresh evidence before publishing, hiring, or debugging an agent. The endpoint is useful because it separates metadata, liveness, and community signals; a single score cannot tell you which layer is broken.

## Request

```bash
curl -sS https://thespawn.io/api/quality-check \
  -H "Content-Type: application/json" \
  --data '{"input":"base/29382"}'
```

`input` accepts:

| Input shape | Example |
| --- | --- |
| The Spawn URL | `https://thespawn.io/agents/base/29382` |
| 8004scan URL | `https://8004scan.io/agents/8453/29382` |
| Chain slug and token | `base/29382` |
| Chain ID and token | `8453:29382` |
| Host lookup | `socialintel.dev` |

The maximum input length is `500` characters.

Use `base:29382` with the `spawnr check` CLI. The public HTTP API accepts the slash form, `base/29382`, or the chain ID form, `8453:29382`.

## Node example

```js
const response = await fetch("https://thespawn.io/api/quality-check", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ input: "base/29382" })
});

const body = await response.json();

if (!response.ok) {
  const message = body.message || body.error || `Quality check failed with status ${response.status}`;
  throw new Error(message);
}

console.log(`${body.agent?.name}: ${body.scores?.quality_tier ?? body.tier}`);
```

## Response

```json
{
  "agent": {
    "agent_id": 29382,
    "chain_id": 8453,
    "chain_slug": "base",
    "name": "Social Intel API"
  },
  "scores": {
    "quality_score": 73.7,
    "quality_tier": "B",
    "works_today": true,
    "tool_call_ok": true,
    "proven_callable": true,
    "x402_verified": true,
    "metadata_score": 23,
    "liveness_score": 50,
    "community_score": 1
  },
  "liveness_checks": [],
  "recommendations": []
}
```

## Rate limits

The public checker is limited to 5 checks per minute and 50 checks per hour per IP.

## Failure

| Status | Meaning |
| --- | --- |
| `422` | The input could not be parsed, or a host lookup found no agent. |
| `404` | The parsed chain/token pair was not found. |
| `429` | The checker rate limit was reached. |

Missing input:

```json
{
  "message": "The input field is required.",
  "errors": {
    "input": ["The input field is required."]
  }
}
```

Host lookups can return multiple candidates. Use the exact `chain/agentId` form when you need deterministic checks.
